# STARCAST 법적 고지

앱은 서버가 없고, 아이의 정보를 기기 밖으로 보내지 않습니다.

- 한국어: https://twostepsaheadorg.github.io/starcast-legal/
- English: https://twostepsaheadorg.github.io/starcast-legal/privacy.en.html
- 日本語: https://twostepsaheadorg.github.io/starcast-legal/privacy.ja.html

원본(마크다운)은 앱 저장소의 `docs/legal/` 에 있습니다. 여기 HTML 은 거기서 변환한 것입니다.
