랜덤 신화 디펜스 (Random Myth Defense) 개인정보 처리방침

시행일: 2026-10-14

요약

  • 회원가입·로그인·광고·인앱 결제가 없습니다. 게임 기록은 이 기기 안에만 둡니다.
  • 회사는 서버가 없고, 이용자의 정보를 받지 않습니다.
  • iPhone·iPad 에서는 Apple 의 Game Center 순위표에 최고 기록이 올라갈 수 있습니다. Apple 이 처리하며 회사는 받지 않습니다(1.2).
  • 회사는 분석·충돌 보고 도구를 넣지 않았습니다. 다만 게임 엔진(Unity)이 기기 사양 통계를 익명으로 Unity 에 보냅니다(1.3).
  • 친구 도전장 코드는 판 번호·모드·맵·단계·점수만 담은 12글자이며, 이용자가 직접 복사해 전합니다(4절).

1. 처리하는 정보와 목적

1.1 기기 안에만 두는 것

무엇왜어디에
게임 진행 (암브로시아, 열린 영웅·카드·레벨, 출전 영웅, 무기·강화, 맵·단계별 별과 최고 기록, 끝없는 탑 기록, 오늘의 도전 기록, 일일 임무·업적, 판 수 같은 누적 기록)이어서 하려고, 기기 안 순위 화면에 보여 주려고기기 (앱 전용 저장 공간의 파일)

회사는 위 정보를 서버로 받지 않습니다. 앱을 지우면 모두 지워집니다. 다만 Game Center 에 이미 올라간 점수는 Apple 에 남습니다(1.2).

1.2 Apple 이 처리하는 것 — Game Center 순위표 (iPhone·iPad 만)

iOS 판은 Apple 의 Game Center(GameKit)로 전 세계 순위표를 제공합니다. 앱을 켜면 Game Center 연결을 시도합니다.

  • 기기에 이미 Game Center 로그인이 되어 있으면 앱 안에서 따로 묻지 않고 자동으로 연결되어, 아래 기록이 순위표로 올라갑니다.
  • 로그인이 되어 있지 않으면 iOS 가 자체 로그인 화면을 보여 줄 수 있습니다. 로그인하지 않거나 거절하면 순위표로 아무것도 보내지 않고, 기기 안 기록만으로 게임을 그대로 할 수 있습니다.
  • 보내지 않게 하려면 iOS 설정 › Game Center 에서 로그아웃하면 됩니다.

Game Center 에 처음 연결될 때, 연결 전에 기기에 저장된 최고 기록도 한 번 다시 보냅니다(연결 전에 끝난 판이 빠지지 않게). 앱은 Game Center 의 닉네임·플레이어 ID 같은 계정 정보를 읽지 않으며, 회사는 이 정보를 받지 않습니다. Game Center 계정과 순위표에서 다른 이용자에게 보이는 이름·친구 기능은 Apple 이 Apple 의 개인정보 처리방침과 Game Center 설정에 따라 처리합니다.

Android 판에는 온라인 순위표가 없습니다. 순위는 기기 안 기록으로만 보여 주며, Google Play 게임즈 서비스를 쓰지 않습니다.

1.3 Unity 가 받는 것 — 게임 엔진의 기기 사양 통계

이 게임을 만든 엔진(Unity)은 앱을 실행할 때 기기 사양 통계를 Unity 로 보냅니다. 엔진에 내장된 기능이라 회사가 끌 수 없으며, 회사는 이 정보를 받지 않습니다. 이름·연락처·게임 기록·광고 ID 는 들어 있지 않습니다.

2. 나이와 어린이

이 앱은 나이를 묻지 않으며 나이 화면이 없습니다. 회사는 어린이를 포함해 누구에게서도 정보를 직접 받지 않으므로, 회사가 하는 처리 중 법정대리인의 동의가 필요한 것은 없습니다. 1.3 의 엔진 통계는 나이와 관계없이 같은 방식으로 Unity 로 전송됩니다. 어린이의 Game Center 이용 여부와 공개 범위는 보호자가 iOS 의 스크린 타임·Game Center 설정으로 정할 수 있습니다.

3. 순위표

순위 화면의 신화 인물 기록은 게임에 미리 들어 있는 고정 기록이며 실제 이용자가 아닙니다. 실제 이용자와 겨루는 순위표는 iOS 의 Game Center 뿐입니다(1.2). 자유 입력·대화 기능은 없습니다. Game Center 순위표에서 내 기록을 지우고 싶으면 12절의 이메일로 요청해 주세요. 확인에 필요한 정보(Game Center 에 보이는 이름과 순위표 등)를 여쭌 뒤 App Store Connect 의 관리 도구로 지웁니다.

4. 친구 도전장 코드와 클립보드

  • 결과 화면의 「도전장 복사」는 12글자 코드를 기기의 클립보드에 복사합니다. 코드에는 판 번호(소환 순서를 정하는 수)·모드·맵·단계·점수와 오타 확인용 글자 하나만 들어 있으며, 이름·기기 정보·식별자는 들어 있지 않습니다.
  • 코드를 친구에게 전할지, 어떤 방법으로 전할지는 이용자가 직접 정합니다. 앱은 코드를 어디로도 보내지 않습니다.
  • 도전장 넣기 화면의 「붙여넣기」를 누를 때만 클립보드를 읽으며, 코드에 쓰는 글자만 골라 최대 12글자를 쓰고 나머지는 버립니다. iOS 가 붙여넣기 허락을 물을 수 있습니다. 코드는 정해진 글자판으로만 넣으며 자유 입력은 없습니다.

5. 진동 · 알림 · 기기 권한

  • 진동: iPhone 에서는 합성·보스 같은 순간에 짧은 햅틱을 냅니다. iOS 「동작 줄이기」 설정을 기기 안에서 읽어 화면 흔들림을 줄입니다. Android 판은 진동을 쓰지 않습니다.
  • 알림: 알림을 보내지 않습니다.
  • 권한: 카메라·마이크·위치·사진·연락처를 요청하지 않습니다. Android 의 인터넷 권한은 게임 엔진이 기본으로 넣는 것이며, Android 판이 인터넷으로 보내는 것은 1.3 의 엔진 통계뿐입니다.

7. 이용자의 권리와 행사 방법

  • 앱 삭제: 기기 안의 정보(게임 진행·기록)는 앱을 지우면 모두 지워집니다. Game Center 에 올라간 점수는 앱을 지워도 Apple 에 남습니다.
  • Game Center: iOS 설정 › Game Center 에서 로그아웃하거나 공개 범위를 바꿀 수 있습니다. 순위표 기록 삭제는 3절처럼 이메일로 요청할 수 있습니다.
  • 열람·정정·삭제·처리정지 요청: 12절의 이메일로 요청하면 지체 없이 처리합니다. 회사가 직접 가진 정보는 문의 이메일뿐이며, Unity·Apple 이 가진 정보는 각 회사에 요청하도록 안내하거나 우리가 할 수 있는 범위(순위표 기록 삭제 등)에서 처리합니다.
  • 법정대리인도 아동을 대신해 위 권리를 행사할 수 있습니다.

8. 보유 기간과 파기

  • 기기 안 정보: 앱을 삭제할 때까지. 앱 삭제로 파기됩니다.
  • Unity·Apple 이 받은 정보: 6절 표의 기간.
  • 문의 이메일: 처리를 마친 뒤 지체 없이 삭제합니다. 법령이 보관을 요구하면 그 기간 동안만 따로 보관합니다.
  • 파기는 전자 파일을 복구할 수 없는 방법으로 지우는 방식으로 합니다.

9. 안전성 확보 조치

  • 회사는 서버가 없고 이용자 정보를 모으지 않아 보관 정보를 최소로 둡니다.
  • 엔진 통계와 Game Center 전송은 암호화된 연결로 이루어집니다.
  • 문의 이메일은 개인정보 보호책임자가 관리합니다.

10. 하지 않는 것

  • 회원가입·로그인 없음 (Game Center 는 Apple 계정을 쓰며 회사 계정이 아님)

  • 회사가 넣은 분석·충돌 보고 도구 없음 (엔진의 기기 사양 통계는 1.3)
  • 회사 서버 없음
  • 위치·연락처·카메라·마이크·사진을 쓰지 않음
  • 알림 없음
  • 개인정보 판매 없음
  • 자유 텍스트 입력·채팅 없음
